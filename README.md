# 🕌 Eslamic API

A **RESTful API** built with **Laravel** that provides Islamic content and services such as **prayer times, Quran verses, Azkar, Duas, and other related data** for consumption by frontend or mobile applications.

---

## 🚀 Project Overview

Eslamic API is designed to serve as a **central backend service** for Islamic applications.  
It enables developers to easily integrate authentic Islamic data into **mobile apps, websites, or third-party systems** through well-structured RESTful endpoints.

The project focuses on:
- Clean and scalable API architecture
- Efficient database design
- Standardized JSON responses
- High performance and easy integration

---

## 🧩 Features

### 📿 Islamic Content
- Quran verses (by Surah / Ayah)
- Azkar (morning, evening, sleep, etc.)
- Duas with references
- Categorized Islamic content

### 🕌 Prayer Services
- Prayer times by city/location
- Daily schedules

### ⚙ API Capabilities
- RESTful endpoints
- JSON responses
- Pagination support
- Relationship handling between resources
- Ready for mobile & frontend consumption
